LOGIN PAGE WORKING: HTML Kahan Hai Aur Kaun Kaun Si Files Use Ho Rahi Hain
================================================================================

Jab aap browser mein "http://127.0.0.1:8000" ya "http://127.0.0.1:8000/login" kholte ho,
toh total 4 main files milkar Login Page ko screen par banati hain:

--------------------------------------------------------------------------------
1. ROUTE FILE: routes/web.php
--------------------------------------------------------------------------------
* Kaam: Yeh decide karti hai ki browser ki request kahan jayegi.
* Code:
    Route::get('/login', [AuthController::class, 'showLoginForm'])->name('login');
* Matlab: Jab koi "/login" kholega, toh "AuthController" ke andar "showLoginForm()" function chala do.


--------------------------------------------------------------------------------
2. CONTROLLER FILE: app/Http/Controllers/AuthController.php
--------------------------------------------------------------------------------
* Kaam: Yeh PHP logic chalata hai aur View (HTML file) ko call karta hai.
* Code:
    public function showLoginForm() {
        return view('auth.login');
    }
* Matlab: Yeh Laravel ko bolta hai ki "resources/views/auth/login.blade.php" ko screen par dikhao.


--------------------------------------------------------------------------------
3. MASTER LAYOUT FILE: resources/views/layouts/auth.blade.php
--------------------------------------------------------------------------------
* Kaam: Yeh bahar ka main HTML skeleton (dhancha) hai:
    - <!DOCTYPE html>, <html>, <head> tags
    - Google Fonts (Plus Jakarta Sans)
    - Tailwind CSS library
    - Dark background colour aur glowing ambient lights
    - Ek center box jisme likha hai: @yield('content')
      (Is @yield('content') ki jagah par login form aakar baith jata hai).


--------------------------------------------------------------------------------
4. PAGE CONTENT (FORM) FILE: resources/views/auth/login.blade.php
--------------------------------------------------------------------------------
* Kaam: Yeh actual Login Card aur Form ki HTML hai:
    - Header: "Attendance Portal" aur logo
    - 1-Click Quick Demo Login buttons (Admin / Employee)
    - <form action="/login" method="POST">
    - @csrf (Security token)
    - Email aur Password ke input boxes
    - "Sign In to System" button
* Khas Baat: 
    Is file ke sabse upar likha hai:
    @extends('layouts.auth')
    Iska matlab yeh apna pura form "layouts/auth.blade.php" ke andar inject kar deta hai.

ROUTES (routes/web.php) EXPLAINED IN SIMPLE WORDS:
================================================================================

1. Route::get('/', ...)
   * Meaning: Jab koi website ka main link (http://127.0.0.1:8000/) kholega,
     toh usko direct "/login" page par bhej do.

2. Route::get('/login', [AuthController::class, 'showLoginForm'])
   * Meaning: Jab koi browser mein "/login" likhega,
     toh AuthController ka showLoginForm() chalega aur login page dikhayega.

3. Route::post('/login', [AuthController::class, 'login'])
   * Meaning: Jab user form mein email aur password daal kar submit dabayega (POST),
     toh AuthController ka login() chalega aur password check karega.

4. Route::post('/logout', [AuthController::class, 'logout'])
   * Meaning: Jab user logout button dabayega,
     toh AuthController ka logout() chalega aur user logout ho jayega.

5. Route::middleware(['auth', 'role:admin'])->group(...)
   * Meaning: Iske andar jo bhi routes hain (jaise /admin/dashboard),
     wahan sirf wohi ja sakta hai jo:
     - Logged in ho (auth)
     - Aur uska role "admin" ho (role:admin)

6. Route::middleware(['auth', 'role:employee'])->group(...)
   * Meaning: Iske andar jo bhi routes hain (jaise /employee/dashboard),
     wahan sirf normal employee ja sakta hai.

================================================================================
KNOWLEDGE SPOTLIGHT: "->name('login')" KYA HAI AUR KYUN LAGATE HAIN?
================================================================================
Iska simple matlab hai: Route ko ek "NICKNAME" (Pyaar ka naam) dena!

Kyun dete hain nickname?
1. Real Life Example:
   Kisi ka lamba naam hai: "Dr. Vikramaditya Singh Shekhawat",
   gharwale usko nickname de dete hain: "Vicky".
   Ab har jagah poora lamba naam lene ki zaroorat nahi, bas "Vicky" bolo sab samajh jayenge.

2. Code Example:
   URL hai: "/login" ya kal ko ho jaye: "/portal/v2/secure-user-login"
   Agar humne ->name('login') de diya,
   toh Controller ya HTML form mein hume poora URL nahi likhna padega,
   hum seedha likhenge:
   route('login')

3. Sabse Bada Fayda (Interview Answer):
   Agar kal ko boss bole: "/login ka URL badal kar /signin kar do",
   toh hume 50 alag-alag files mein jakar /login nahi dhoondhna padega!
   Sirf routes/web.php mein URL badal do,
   baaki poore project mein route('login') apne aap naya URL pakad lega!

================================================================================
KNOWLEDGE SPOTLIGHT: "middleware()->group(function() { ... })" KYA HAI?
================================================================================
1. "middleware": Ek Security Guard (Bouncer) hai jo check karta hai:
   - Kya user logged in hai?
   - Kya user Admin hai?

2. "group(function() { ... })":
   Maan lo ek kamre ke andar 10 routes hain (Dashboard, Employee Add, Report, etc.).
   Ab ya toh tum 10 ke 10 routes par alag-alag guard lagao (mehnat zyada),
   YA fir kamre ke main darwaze par ek baar guard khada kar do:
   Route::middleware([...])->group(function () {
       // Ab is group ke andar jo bhi route aayega, 
       // guard sabko automatically check karega!
   });

KAHAN USE HO RAHA HAI YEH "name('login')"?
================================================================================
Project mein yeh abhi in jagahon par use ho raha hai:

1. app/Http/Middleware/Authenticate.php (Line 18):
   Jab koi bina login kiye direct protected page kholta hai,
   toh Laravel automatically usko redirect karta hai:
   return route('login');

2. resources/views/auth/login.blade.php:
   Form submit karne ke liye:
   <form action="{{ route('login.submit') }}" method="POST">
   (Yeh doosre route ka name hai jo web.php mein diya tha: ->name('login.submit'))

3. Aur jab hum Logout karte hain ya User Deactivated hota hai:
   redirect()->route('login');
